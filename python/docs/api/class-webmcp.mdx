[WebMCP] exposes the tools that a frame registers through the experimental [WebMCP](https://webmachinelearning.github.io/webmcp/) browser API, `navigator.modelContext`. It lists the tools and calls them.

Instances are accessed through [frame.webmcp](/api/class-frame.mdx#frame-webmcp). [page.webmcp](/api/class-page.mdx#page-webmcp) is the instance of the main frame.

:::note

WebMCP is an experimental browser feature. Chromium enables it with the `--enable-features=WebMCP` launch argument, Firefox with the `dom.modelcontext.enabled` and `dom.modelcontext.testing.enabled` preferences. WebKit does not implement it.
:::

Tool names, descriptions, input schemas and results are provided by the page, so treat them as untrusted input.

## Methods

### call_tool {/* #web-mcp-call-tool */}

<font size="2" style={{position: "relative", top: "-20px"}}>Added in: v1.64</font><x-search>webMCP.call_tool</x-search>

Calls a tool registered by the frame and returns its result. The result is whatever the tool's `execute` function resolved to, typically an object with a `content` array. A result with `isError: true` is returned as is. The method throws when the tool is not registered or its `execute` function throws.

**Usage**

```python
web_mcp.call_tool(name)
web_mcp.call_tool(name, **kwargs)
```

**Arguments**
- `name` [str]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-name"/><a href="#web-mcp-call-tool-option-name" class="list-anchor">#</a>
  
  Name of the tool, as reported by [web_mcp.tools()](/api/class-webmcp.mdx#web-mcp-tools).
- `input` [Dict] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-input"/><a href="#web-mcp-call-tool-option-input" class="list-anchor">#</a>
  
  Input for the tool, matching its `inputSchema`. Defaults to an empty object.
- `timeout` [float] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-timeout"/><a href="#web-mcp-call-tool-option-timeout" class="list-anchor">#</a>
  
  Maximum time in milliseconds. Defaults to `30000` (30 seconds). Pass `0` to disable timeout. The default value can be changed by using the [browser_context.set_default_timeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) or [page.set_default_timeout()](/api/class-page.mdx#page-set-default-timeout) methods.

**Returns**
- [Dict]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-return"/><a href="#web-mcp-call-tool-return" class="list-anchor">#</a>

### tools {/* #web-mcp-tools */}

<font size="2" style={{position: "relative", top: "-20px"}}>Added in: v1.64</font><x-search>webMCP.tools</x-search>

Returns the tools currently registered by the frame. Throws if the browser was launched without WebMCP support, see the note above for the launch options that enable it.

[page.webmcp](/api/class-page.mdx#page-webmcp) covers the main frame only, child frames list their tools through their own [frame.webmcp](/api/class-frame.mdx#frame-webmcp).

**Usage**

```python
web_mcp.tools()
web_mcp.tools(**kwargs)
```

**Arguments**
- `timeout` [float] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-tools-option-timeout"/><a href="#web-mcp-tools-option-timeout" class="list-anchor">#</a>
  
  Maximum time in milliseconds. Defaults to `30000` (30 seconds). Pass `0` to disable timeout. The default value can be changed by using the [browser_context.set_default_timeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) or [page.set_default_timeout()](/api/class-page.mdx#page-set-default-timeout) methods.

**Returns**
- [List]\[[Dict]\]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-tools-return"/><a href="#web-mcp-tools-return" class="list-anchor">#</a>
  - `name` [str]
    
    Tool name, unique within the frame.
  - `description` [str]
    
    Tool description.
  - `inputSchema` [Dict] *(optional)*
    
    JSON Schema of the tool input, when the page provides one.
  - `annotations` [Dict] *(optional)*
    - `readOnly` [bool] *(optional)*
      
      The tool does not modify any state.
    - `untrustedContent` [bool] *(optional)*
      
      The tool output may contain third-party content.
    - `consequential` [bool] *(optional)*
      
      The tool takes a consequential action, such as placing an order.
    
    Hints the page provides about the tool.
