[WebMCP] exposes the tools that a frame registers through the experimental [WebMCP](https://webmachinelearning.github.io/webmcp/) browser API, `navigator.modelContext`. It lists the tools, reports when the set of tools changes, and calls the tools.

Instances are accessed through [frame.webmcp](/api/class-frame.mdx#frame-webmcp). [page.webmcp](/api/class-page.mdx#page-webmcp) is the instance of the main frame. Call [webMCP.enable()](/api/class-webmcp.mdx#web-mcp-enable) before using the other methods.

:::note

WebMCP is an experimental browser feature. Chromium enables it with the `--enable-features=WebMCP` launch argument, Firefox with the `dom.modelcontext.enabled` preference. WebKit does not implement it.
:::

Tool names, descriptions, input schemas and results are provided by the page, so treat them as untrusted input.

```js
const browser = await chromium.launch({ args: ['--enable-features=WebMCP'] });
const page = await browser.newPage();
await page.webmcp.enable();
await page.goto('https://example.com');

for (const tool of await page.webmcp.tools())
  console.log(tool.name, tool.description);

const result = await page.webmcp.callTool('add', { a: 2, b: 40 });
```

## Methods

### callTool {/* #web-mcp-call-tool */}

<font size="2" style={{position: "relative", top: "-20px"}}>Added in: v1.64</font><x-search>webMCP.callTool</x-search>

Calls a tool registered by the frame and returns its result. The result is whatever the tool's `execute` function resolved to, typically an object with a `content` array. A result with `isError: true` is returned as is. The method throws when the tool is not registered or its `execute` function throws.

```js
const result = await page.webmcp.callTool('add', { a: 2, b: 40 });
console.log(result.content[0].text); // "42"
```

**Usage**

```js
await webMCP.callTool(name);
await webMCP.callTool(name, input, options);
```

**Arguments**
- `name` [string]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-name"/><a href="#web-mcp-call-tool-option-name" class="list-anchor">#</a>
  
  Name of the tool, as reported by [webMCP.tools()](/api/class-webmcp.mdx#web-mcp-tools).
- `input` [Serializable] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-input"/><a href="#web-mcp-call-tool-option-input" class="list-anchor">#</a>
  
  Input for the tool, matching its `inputSchema`. Defaults to an empty object.
- `options` [Object] *(optional)*
  - `timeout` [number] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-timeout"/><a href="#web-mcp-call-tool-option-timeout" class="list-anchor">#</a>
    
    Maximum time in milliseconds. Defaults to `0` - no timeout. The default value can be changed via `actionTimeout` option in the config, or by using the [browserContext.setDefaultTimeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) or [page.setDefaultTimeout()](/api/class-page.mdx#page-set-default-timeout) methods.

**Returns**
- [Promise]&lt;[Serializable]&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-return"/><a href="#web-mcp-call-tool-return" class="list-anchor">#</a>

### disable {/* #web-mcp-disable */}

<font size="2" style={{position: "relative", top: "-20px"}}>Added in: v1.64</font><x-search>webMCP.disable</x-search>

Stops tracking the tools that the frame registers and stops emitting [webMCP.on('toolschanged')](/api/class-webmcp.mdx#web-mcp-event-tools-changed). Disposing the [Disposable] returned by [webMCP.enable()](/api/class-webmcp.mdx#web-mcp-enable) does the same.

**Usage**

```js
await webMCP.disable();
```

**Returns**
- [Promise]&lt;[void]&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-disable-return"/><a href="#web-mcp-disable-return" class="list-anchor">#</a>

### enable {/* #web-mcp-enable */}

<font size="2" style={{position: "relative", top: "-20px"}}>Added in: v1.64</font><x-search>webMCP.enable</x-search>

Starts tracking the tools that the frame registers, so that [webMCP.tools()](/api/class-webmcp.mdx#web-mcp-tools), [webMCP.callTool()](/api/class-webmcp.mdx#web-mcp-call-tool) and [webMCP.on('toolschanged')](/api/class-webmcp.mdx#web-mcp-event-tools-changed) work. Throws if the browser was launched without WebMCP support, see the note above for the launch options that enable it. Returns a [Disposable] that disables the tracking again.

Tracking is per frame. [page.webmcp](/api/class-page.mdx#page-webmcp) covers the main frame only, child frames are tracked through their own [frame.webmcp](/api/class-frame.mdx#frame-webmcp).

Chromium reports tool registrations natively. Firefox does not, so Playwright instruments `navigator.modelContext` in the page to observe registrations. Tools registered before the call are picked up as well.

```js
await page.webmcp.enable();
await page.goto('https://example.com');
console.log(await page.webmcp.tools());
```

**Usage**

```js
await webMCP.enable();
```

**Returns**
- [Promise]&lt;[Disposable]&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-enable-return"/><a href="#web-mcp-enable-return" class="list-anchor">#</a>

### tools {/* #web-mcp-tools */}

<font size="2" style={{position: "relative", top: "-20px"}}>Added in: v1.64</font><x-search>webMCP.tools</x-search>

Returns the tools currently registered by the frame.

**Usage**

```js
await webMCP.tools();
await webMCP.tools(options);
```

**Arguments**
- `options` [Object] *(optional)*
  - `timeout` [number] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-tools-option-timeout"/><a href="#web-mcp-tools-option-timeout" class="list-anchor">#</a>
    
    Maximum time in milliseconds. Defaults to `0` - no timeout. The default value can be changed via `actionTimeout` option in the config, or by using the [browserContext.setDefaultTimeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) or [page.setDefaultTimeout()](/api/class-page.mdx#page-set-default-timeout) methods.

**Returns**
- [Promise]&lt;[Array]&lt;[Object]&gt;&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-tools-return"/><a href="#web-mcp-tools-return" class="list-anchor">#</a>
  - `name` [string]
    
    Tool name, unique within the frame.
  - `description` [string]
    
    Tool description.
  - `inputSchema` [Serializable] *(optional)*
    
    JSON Schema of the tool input, when the page provides one.
  - `annotations` [Object] *(optional)*
    - `readOnly` [boolean] *(optional)*
      
      The tool does not modify any state.
    - `untrustedContent` [boolean] *(optional)*
      
      The tool output may contain third-party content.
    - `consequential` [boolean] *(optional)*
      
      The tool takes a consequential action, such as placing an order.
    
    Hints the page provides about the tool.

### waitForEvent {/* #web-mcp-wait-for-event */}

<font size="2" style={{position: "relative", top: "-20px"}}>Added in: v1.64</font><x-search>webMCP.waitForEvent</x-search>

Waits for the event to fire and passes its value into the predicate function. Returns when the predicate returns a truthy value. Throws if the page is closed before the event is fired. Returns the event data value.

```js
const toolsPromise = page.webmcp.waitForEvent('toolschanged');
await page.getByRole('button', { name: 'Sign in' }).click();
const tools = await toolsPromise;
```

**Usage**

```js
await webMCP.waitForEvent(event);
await webMCP.waitForEvent(event, optionsOrPredicate, options);
```

**Arguments**
- `event` [string]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-wait-for-event-option-event"/><a href="#web-mcp-wait-for-event-option-event" class="list-anchor">#</a>
  
  Event name, same one typically passed into `*.on(event)`.
- `optionsOrPredicate` [function] | [Object] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-wait-for-event-option-options-or-predicate"/><a href="#web-mcp-wait-for-event-option-options-or-predicate" class="list-anchor">#</a>
  - `predicate` [function]
    
    Receives the event data and resolves to truthy value when the waiting should resolve.
  - `timeout` [number] *(optional)*
    
    Maximum time to wait for in milliseconds. Defaults to `0` - no timeout. The default value can be changed via `actionTimeout` option in the config, or by using the [browserContext.setDefaultTimeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) or [page.setDefaultTimeout()](/api/class-page.mdx#page-set-default-timeout) methods.
  
  Either a predicate that receives an event or an options object. Optional.
- `options` [Object] *(optional)*
  - `predicate` [function] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-wait-for-event-option-predicate"/><a href="#web-mcp-wait-for-event-option-predicate" class="list-anchor">#</a>
    
    Receives the event data and resolves to truthy value when the waiting should resolve.
  - `signal` [AbortSignal] *(optional)* <font size="2">Added in: v1.62</font><a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-wait-for-event-option-signal"/><a href="#web-mcp-wait-for-event-option-signal" class="list-anchor">#</a>
    
    Allows to cancel the waiting using an [`AbortSignal`](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal). If the signal is aborted, the waiting will be aborted and the operation will throw an error. Note that providing a signal does not disable the default timeout, which can be changed using [browserContext.setDefaultTimeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout); pass `timeout: 0` to disable the timeout entirely.

**Returns**
- [Promise]&lt;[Object]&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-wait-for-event-return"/><a href="#web-mcp-wait-for-event-return" class="list-anchor">#</a>

## Events

### on('toolschanged') {/* #web-mcp-event-tools-changed */}

<font size="2" style={{position: "relative", top: "-20px"}}>Added in: v1.64</font><x-search>webMCP.on('toolschanged')</x-search>

Emitted while WebMCP is enabled, whenever the set of tools registered by the frame changes, for example when the page registers or unregisters a tool, or when the frame navigates away. The argument is the new list of tools, the same one [webMCP.tools()](/api/class-webmcp.mdx#web-mcp-tools) returns.

```js
page.webmcp.on('toolschanged', tools => {
  console.log('tools are now', tools.map(tool => tool.name));
});
```

**Usage**

```js
webMCP.on('toolschanged', data => {});
```

**Event data**
- [Array]&lt;[Object]&gt;
  - `name` [string]
    
    Tool name, unique within the frame.
  - `description` [string]
    
    Tool description.
  - `inputSchema` [Serializable] *(optional)*
    
    JSON Schema of the tool input, when the page provides one.
  - `annotations` [Object] *(optional)*
    - `readOnly` [boolean] *(optional)*
      
      The tool does not modify any state.
    - `untrustedContent` [boolean] *(optional)*
      
      The tool output may contain third-party content.
    - `consequential` [boolean] *(optional)*
      
      The tool takes a consequential action, such as placing an order.
    
    Hints the page provides about the tool.
