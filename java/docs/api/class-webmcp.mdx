[WebMCP] exposes the tools that a frame registers through the experimental [WebMCP](https://webmachinelearning.github.io/webmcp/) browser API, `navigator.modelContext`. It lists the tools and calls them.

Instances are accessed through [Frame.webmcp()](/api/class-frame.mdx#frame-webmcp). [Page.webmcp()](/api/class-page.mdx#page-webmcp) is the instance of the main frame.

:::note

WebMCP is an experimental browser feature. Chromium enables it with the `--enable-features=WebMCP` launch argument, Firefox with the `dom.modelcontext.enabled` and `dom.modelcontext.testing.enabled` preferences. WebKit does not implement it.
:::

Tool names, descriptions, input schemas and results are provided by the page, so treat them as untrusted input.

## Methods

### callTool {/* #web-mcp-call-tool */}

<font size="2" style={{position: "relative", top: "-20px"}}>Added in: v1.64</font><x-search>webMCP.callTool</x-search>

Calls a tool registered by the frame and returns its result. The result is whatever the tool's `execute` function resolved to, typically an object with a `content` array. A result with `isError: true` is returned as is. The method throws when the tool is not registered or its `execute` function throws.

**Usage**

```java
WebMCP.callTool(name);
WebMCP.callTool(name, input, options);
```

**Arguments**
- `name` [String]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-name"/><a href="#web-mcp-call-tool-option-name" class="list-anchor">#</a>
  
  Name of the tool, as reported by [WebMCP.tools()](/api/class-webmcp.mdx#web-mcp-tools).
- `input` [Object] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-input"/><a href="#web-mcp-call-tool-option-input" class="list-anchor">#</a>
  
  Input for the tool, matching its `inputSchema`. Defaults to an empty object.
- `options` `WebMCP.CallToolOptions` *(optional)*
  - `setTimeout` [double] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-option-timeout"/><a href="#web-mcp-call-tool-option-timeout" class="list-anchor">#</a>
    
    Maximum time in milliseconds. Defaults to `30000` (30 seconds). Pass `0` to disable timeout. The default value can be changed by using the [BrowserContext.setDefaultTimeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) or [Page.setDefaultTimeout()](/api/class-page.mdx#page-set-default-timeout) methods.

**Returns**
- [Object]<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-call-tool-return"/><a href="#web-mcp-call-tool-return" class="list-anchor">#</a>

### tools {/* #web-mcp-tools */}

<font size="2" style={{position: "relative", top: "-20px"}}>Added in: v1.64</font><x-search>webMCP.tools</x-search>

Returns the tools currently registered by the frame. Throws if the browser was launched without WebMCP support, see the note above for the launch options that enable it.

[Page.webmcp()](/api/class-page.mdx#page-webmcp) covers the main frame only, child frames list their tools through their own [Frame.webmcp()](/api/class-frame.mdx#frame-webmcp).

**Usage**

```java
WebMCP.tools();
WebMCP.tools(options);
```

**Arguments**
- `options` `WebMCP.ToolsOptions` *(optional)*
  - `setTimeout` [double] *(optional)*<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-tools-option-timeout"/><a href="#web-mcp-tools-option-timeout" class="list-anchor">#</a>
    
    Maximum time in milliseconds. Defaults to `30000` (30 seconds). Pass `0` to disable timeout. The default value can be changed by using the [BrowserContext.setDefaultTimeout()](/api/class-browsercontext.mdx#browser-context-set-default-timeout) or [Page.setDefaultTimeout()](/api/class-page.mdx#page-set-default-timeout) methods.

**Returns**
- [List]&lt;Tools&gt;<a aria-hidden="true" tabIndex="-1" class="list-anchor-link" id="web-mcp-tools-return"/><a href="#web-mcp-tools-return" class="list-anchor">#</a>
  - `name` [String]
    
    Tool name, unique within the frame.
  - `description` [String]
    
    Tool description.
  - `inputSchema` [Object] *(optional)*
    
    JSON Schema of the tool input, when the page provides one.
  - `annotations` Annotations *(optional)*
    - `readOnly` [boolean] *(optional)*
      
      The tool does not modify any state.
    - `untrustedContent` [boolean] *(optional)*
      
      The tool output may contain third-party content.
    - `consequential` [boolean] *(optional)*
      
      The tool takes a consequential action, such as placing an order.
    
    Hints the page provides about the tool.
